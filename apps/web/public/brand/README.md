# Marca do CommitPost

Três commits entram de um lado, um post sai do outro — o desenho espelha o
modelo de lote do sistema.

| Arquivo | Usar em |
|---|---|
| `commitpost-mark-100.png` | **LinkedIn Developer Portal** (exige quadrado, mínimo 100×100) |
| `commitpost-mark-400.png` | Uso geral: README, slide, avatar |
| `commitpost-mark.svg` | Fonte. Editar aqui e reexportar os PNGs |
| `commitpost-mark-light*` | Variante para fundos escuros |

## Paleta

| | Hex | Papel |
|---|---|---|
| Petrol | `#0E3A42` | fundo |
| Osso | `#EAF2F1` | marca |
| Âmbar | `#FFB03A` | nó de commit — em fundo escuro |
| Âmbar escuro | `#D97A06` | nó de commit — em fundo claro |

O âmbar aparece **uma vez só**, sempre no nó de commit. É a unidade atômica do
produto e a única coisa quente da marca — não usar como cor de apoio.

## Nota de desenho

A espessura da linha e o tamanho dos nós foram calibrados para 24 px, não para
o tamanho grande: no portal do LinkedIn e na tela de consentimento do OAuth a
marca aparece pequena. Ao editar, conferir o resultado nesse tamanho antes de
qualquer outra coisa.
